# Sicherheit

OpenEmployed verarbeitet Buchhaltungs-, Lohn- und Personaldaten. Sicherheitslücken bitte **nicht** als öffentliches Issue melden,
sondern vertraulich über GitHub: Reiter **Security → Report a vulnerability** in diesem Repository.

Bitte angeben: betroffene Version (`VERSION`), Schritte zum Nachstellen und mögliche Auswirkungen. Wir melden uns so schnell
wie möglich und veröffentlichen die Korrektur zusammen mit einem Hinweis.

Hinweise für den Betrieb (Geheimnisse, Backups, Updates): [docs/betrieb.md](docs/betrieb.md).
